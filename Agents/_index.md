> **개요 (한국어):** 자주 쓰는 에이전트/서브에이전트에 대한 운영 메모.

> **What lands here:** Operating notes for an agent or subagent you use often — what it's good at, what to brief it with, gotchas from past runs.
> **Who writes it:** By hand, or Claude's judgment when a pattern in how an agent is used is worth recording.
> **When:** Whenever using an agent teaches you something worth not re-learning next time.

This folder is empty on purpose. Your first session fills it.

This is separate from `Knowledge/` because agent-usage notes have a narrower audience (you, briefing that specific agent again) and a shorter shelf life — they can go stale the moment an agent's own definition changes, whereas `Knowledge/` pages describe more durable how-tos. Nothing here is required for the memory pipeline to work; treat it as optional scratch space for agent-specific lessons.
